Koptan {{ .Chart.AppVersion }} is installed in namespace {{ .Release.Namespace }}.

1. Check the controller:
  kubectl -n {{ .Release.Namespace }} get pods -l "app.kubernetes.io/name={{ include "koptan.name" . }},app.kubernetes.io/instance={{ .Release.Name }}"

2. SelfServices need an agent key. Without it they stay disabled:
  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.agent.keySecret.name }} \
    --from-literal={{ .Values.agent.keySecret.key }}=$(openssl rand -hex 32)
  kubectl -n {{ .Release.Namespace }} rollout restart deployment {{ include "koptan.fullname" . }}

3. Create a Service and watch it build and deploy:
  kubectl get services.koptan.felukka.org,cis.koptan.felukka.org,cds.koptan.felukka.org -A
